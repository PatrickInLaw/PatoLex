# Authority Map

This document defines which documents are authoritative for which topics.

---

## Source of Truth

| Topic | Authoritative Document |
|-------|----------------------|
| Project instructions (for AI) | `CLAUDE.md` |
| Repository layout | `PROJECT_STRUCTURE.md` |
| Structure rationale | `STRUCTURE-DESIGN.md` |
| Current status and priorities | `docs/20_ROADMAP/ROADMAP.md` |
| System architecture | `docs/30_SYSTEM_DESIGN/ARCHITECTURE.md` |
| Data models, schema, metadata | `docs/40_SCHEMA/` |
| Environment setup | `docs/60_OPERATIONS/SETUP.md` |

## Non-Authoritative (Reference Only)

- `docs/00_Inbox/` -- Staging and active comms; not durable
- `docs/80_PROJECT_HISTORY/` -- Historical context, not current truth
- `docs/99_ARCHIVE/` -- Deprecated artifacts
- Session logs -- Record of what happened, not what is
