# Inbox

This folder is temporary staging space and active comms.

Use it for:

- pasted artifacts awaiting filing
- temporary planning scraps
- comms handoff files (`comms/to-codex.md`, `comms/from-codex.md`, `comms/transcript.md`) -- these are operational, not durable docs

Do not use it for:

- authoritative current docs
- session summaries
- changelogs
- durable audits
- design/system/schema truth

## Start Here

If a file in this folder looks important, first ask:

1. Is it temporary?
2. Has it already been filed somewhere canonical?
3. Should it move into `docs/10_` through `docs/80_` instead?

The `comms/` subfolder is an exception -- those files live here permanently because they are the active Codex CLI <-> Claude Code message channel. The `transcript.md` is auto-appended by `comms-watcher.ps1`.
